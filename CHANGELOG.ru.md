# Журнал изменений

Здесь документируются значимые изменения. Формат основан на Keep a Changelog и Semantic Versioning.

## [1.0.0] — 2026-07-29

### Добавлено

- Интеграция с Docker MCP Gateway и OAuth Atlassian из профиля Docker Desktop.
- Синхронизация Jira по расписанию и настраиваемая генерация Markdown.
- Группировка верхнего уровня по Goal, затем по теме и расположению задачи.
- Просмотрщик со структурой, поиском, scroll-spy и сворачиванием разделов.
- Локальные комментарии с выводом под задачей, панелью управления и автоочисткой.
- JSONL-логирование и просмотр журнала в интерфейсе.
- Документация на английском и русском языках.
- CodeQL, dependency review, npm audit, Dependabot и настройки безопасности репозитория.
